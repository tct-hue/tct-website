## ကွန်ပျူတာပေါ်တွင် တိုက်ရိုက်ဖွင့်ကြည့်နည်း
1. `tct-website.zip` ဖိုင်ကို Right-click နှိပ်၍ **Extract All** လုပ်ပါ။
2. `index.html` ဖိုင်ကို Double-click နှိပ်၍ မည်သည့် Browser (Chrome, Edge, Firefox) ဖြင့်မဆို ချက်ချင်း ဖွင့်ကြည့်နိုင်ပါသည်။
